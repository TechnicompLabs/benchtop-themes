# Benchtop Theme Switcher

GNOME Shell extension that switches the GTK 3 theme (for example adw-gtk3 and adw-gtk3-dark, or Yaru-blue and Yaru-blue-dark) and the Kvantum theme of Qt applications (for example KvLibadwaita and KvLibadwaitaDark) between their light and dark variants when the system's style changes in Settings, Appearance. Part of Technicomp Benchtop Linux, which packages it as `gnome-shell-extension-benchtop-theme-switcher`.

A fork of [Legacy (GTK3) Theme Scheme Auto Switcher](https://github.com/mukul29/legacy-theme-auto-switcher-gnome-extension) by Mukul Joshi. Upstream's `extension.js` header says GPL-2.0-or-later and its repository's `LICENSE` is the AGPL-3.0; the header is kept, and GPL-3.0 code may be combined with AGPL-3.0 code (GPL-3.0, section 13). Changes from it: the name and UUID; the Kvantum theme in `~/.config/Kvantum/kvantum.kvconfig` is switched too (`Name` and `NameDark`; `NameLight` becomes `NameDark`), when that variant exists. Qt applications that use the `kvantum` style pick up the new theme when they start; on TCBL that is Flatpak applications, while host applications use `kvantum-auto` (TCBL's kvantum package) and follow the system's style by themselves.
